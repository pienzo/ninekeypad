Layers

Click a key to change it. Press a key on the real keypad and it lights up here. ● = changed, not yet written. active = the layer the keypad uses now. Layer-switch keys work while this program runs — closing this page does not stop it; “Quit” does.

Key

This key types nothing. While the keypad program runs (its window may be minimized), pressing it switches the keypad's layer. Give every layer such a key, or you cannot switch back from the keypad.

Layouts and backups

A layout is one layer's 9 keys, saved as a file in this program's folder — as many as you like. “Load” puts a layout into the selected layer. Nothing reaches the keypad until you press “Write to keypad”.
